Vitrina Photo App — დაყენების ინსტრუქცია

შიგნით არის 4 მთავარი ფაილი:

1) Code.gs
ეს ჩასვი Google Apps Script-ში.
ეს არის განახლებული ვერსია 1.1 და სჭირდება GitHub საიტთან სწორი მუშაობისთვის.

2) index.html
3) style.css
4) script.js
ეს სამი ფაილი ატვირთე GitHub repository-ში.

Apps Script-ის განახლება:

1. გახსენი შენი Google Sheet.
2. შედი Extensions → Apps Script.
3. Code.gs ფაილში ჩასვი ამ ZIP-ში არსებული ახალი Code.gs-ის სრული კოდი.
4. დარწმუნდი, რომ Script Properties-ში გაქვს:
   IMGBB_API_KEY
5. გაუშვი setupProject.
6. შემდეგ:
   Deploy → Manage deployments → Edit deployment
   Version-ში აირჩიე New version
   დააჭირე Deploy.

GitHub-ზე ატვირთვა:

1. შექმენი ახალი repository.
2. ატვირთე:
   index.html
   style.css
   script.js
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / root
6. Save
7. მიღებულ GitHub Pages ლინკზე გახსენი საიტი ტელეფონით.

3. თუ მონიშნულია ავტომატური რიგითობა, ფოტოები აიტვირთება ასე:

6. კვირის ბოლოს მონიშნავ ფოტოებს ან აირჩევ თარიღს და დააჭერ ZIP-ს.
   ZIP-ში სახელები შენარჩუნდება.
7. როცა აღარ გჭირდება, მონიშნავ და წაშლი.
   ავტომატური წაშლა არ არის.
